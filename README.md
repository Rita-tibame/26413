# 🎨 AI 作品集

使用 AI 技術打造的互動作品集，部署於 Netlify。

---

## 🌐 線上展示

開啟 `index.html` 即可瀏覽所有作品，點擊「開啟遊戲」進入各個互動應用。

---

## 📁 專案結構

```
Netliffy v1/
├── index.html                  # 🏠 首頁 — AI 作品集入口
├── catai_landingpage.html       # 🐱 MeowHealth AI 貓咪照護決策助手
├── sticker-saved.html           # ✨ 萌貼圖生成器 — 3D 立體貼圖
├── water.html                   # 💧 每日喝水紀錄

├── dashboard.html               # 🐾 貓咪照護大調查 — 多視角分析儀表板
├── taiwan_tourist_map.html      # 🗺️ 台灣旅遊景點互動地圖
└── README.md                    # 📄 本說明文件
```

## 🚀 作品介紹

### 1. 🐱 MeowHealth AI — 貓咪異常照護決策助手
- **檔案**: `catai_landingpage.html`
- **說明**: 運用 AI 技術，為貓咪提供專業的健康照護建議與異常行為分析
- **技術**: HTML, Tailwind CSS, JavaScript, Phosphor Icons

### 2. ✨ 萌貼圖生成器 — 3D 立體貼圖
- **檔案**: `sticker-saved.html`
- **說明**: 根據照片自動生成精緻的 3D 數位收藏品貼圖
- **技術**: HTML, Tailwind CSS, Glassmorphism 設計

### 3. 💧 每日喝水紀錄
- **檔案**: `water.html`
- **說明**: 視覺化飲水進度追蹤器，可設定目標、快速記錄，即時顯示達標進度
- **技術**: HTML, Tailwind CSS, JavaScript

### 4. 📊 員工出勤與工時健康度分析儀表板
- **檔案**: `staff record.html`
- **說明**: 上傳 Excel 出勤資料，自動產生圖表與統計指標
- **技術**: HTML, Tailwind CSS, SheetJS, Chart.js, Font Awesome

### 5. 🐾 貓咪照護大調查 — 多視角分析儀表板
- **檔案**: `dashboard.html`
- **說明**: 四種角色觀點切換（內部人員、飼主互動、教育醫療、商業公關），深入解讀貓咪照護市調數據
- **技術**: HTML, Tailwind CSS, Chart.js, Font Awesome, Nunito 字體

### 6. 🗺️ 台灣旅遊景點互動地圖
- **檔案**: `taiwan_tourist_map.html`
- **說明**: 整合 Leaflet 地圖引擎，標記台灣各地景點，提供分類篩選與互動瀏覽
- **技術**: HTML, Tailwind CSS, Leaflet.js, Font Awesome

## 🏠 首頁特色

- 🎵 **背景音樂**: 可透過左上角喇叭按鈕控制播放/暫停
- 🌊 **動態背景**: 漸層光暈動畫搭配噪點紋理
- 🃏 **卡片式設計**: 6 張作品卡片，3 欄 RWD 響應式排版
- ✨ **微動畫**: 浮動圖示、粒子特效、滾動淡入、hover 抬升
- 🎨 **Glassmorphism**: 玻璃擬態風格設計

## 🛠️ 技術棧

## 📦 部署方式

1. 將整個資料夾上傳至 [Netlify](https://www.netlify.com/)
2. 設定 Publish Directory 為根目錄
3. 完成部署後即可透過 Netlify 網址瀏覽
